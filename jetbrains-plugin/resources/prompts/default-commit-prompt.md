## Commit Format

```text
<type>(<scope>): <subject>
```

`scope` can be omitted:

```text
<type>: <subject>
```

Requirements:

- Use an English type.
- The subject is a single sentence describing the change; keep the language consistent across a batch of commits.
- Do not end the subject with a period.
- One commit does one relatively complete thing.
- Avoid vague descriptions such as `update`, `fix bug`, or `changed stuff`.
- Decide type and scope strictly from the actual content of the diff; do not invent changes outside the diff.
- When the diff covers multiple aspects, distill the subject from the most significant one.

## Common Types

- `feat`: a new feature or user-visible capability.
- `fix`: a bug fix, abnormal behavior, or regression.
- `docs`: documentation such as README or CHANGELOG.
- `style`: formatting, style, or layout changes with no logic impact.
- `refactor`: code refactoring without changing user-visible behavior.
- `perf`: performance improvements.
- `test`: adding or updating tests.
- `build`: build scripts, dependencies, or packaging configuration.
- `ci`: CI/CD configuration changes.
- `chore`: maintenance work such as version bumps, cleanup, or tool configuration.
- `sync`: local snapshot commits generated by automatic sync.

## Scope Suggestions

The scope is usually the module or directory the change belongs to. Common examples below; if the module in the diff is not listed, name it after the actual module:

- `sync`: remote sync, Git sync, sync settings.
- `editor`: editor, preview, toolbar, tabs.
- `sidebar`: sidebar, file tree, search, outline.
- `history`: version history, rollback, diff view.
- `settings`: settings window and options.
- `terminal`: bottom terminal.
- `print`: printing and PDF export.
- `ai`: AI assistant and model configuration.
- `tauri`: Rust backend, Tauri commands, desktop integration.
- `theme`: theme, colors, appearance.
- `deps`: dependency changes.
- `release`: release, version number, CHANGELOG.

## Examples

```text
feat(sync): support HTTPS credential login
fix(editor): keep image preview from stealing focus
docs: update release download links
refactor(tauri): share git command timeout handling
build(deps): add tempfile for git askpass helper
chore(release): bump version to 1.0.2
```
